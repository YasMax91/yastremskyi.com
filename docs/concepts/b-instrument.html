case_01 · open source

Groundwork

Risk-based task classification L0–L4, five specialised review agents, eleven automated gates, eleven workflow procedures and a companion-plugin ecosystem, shipped under MIT with semantic versioning.

  • Bash

case_02 · applied AI

Voice to structured data

Speech becomes a validated task rather than a guess: Whisper transcription tuned with domain vocabulary, schema-constrained extraction at temperature zero, relative time such as “tomorrow at six” resolved to an absolute, timezone-aware instant. Queued, so HTTP answers instantly and the result arrives over WebSocket.

  • Whisper STT
  • Tool calling
  • WebSocket
  • Queues
  • Hebrew
the subtle partThe provider is mocked in CI, so the suite never calls a paid API — and a model upgrade is caught by response-regression tests instead of by a user.
case_03 · money

Payments, clearing and tax documents

PCI card tokenization where raw card data is never stored or returned, hierarchical payment requests, idempotency-keyed clearing transactions, money as decimal strings with bcmath rather than floats, multi-currency and VAT, signed-webhook reconciliation, standing orders and direct-debit collection.

  • Laravel
  • bcmath
  • Idempotency
  • Signed webhooks
  • VAT
the subtle partA zero-total tax document is rejected by the provider — so those items have to be closed locally instead, or the whole issuance silently fails.
case_04 · platform

Multi-market commerce platform

One Laravel codebase cloned per market with config-driven currency, locale and timezone: storefront JSON API, retail and wholesale pricing and discount engine, driver-abstracted payments and delivery, buyer auth over JWT, OAuth and email OTP, plus an ERP catalogue sync.

  • Laravel 12
  • JSON API
  • JSON-LD
  • Job chains
  • Typed DTOs
the subtle partCatalogue sync from the ERP stages every product change as a typed DTO for review before it applies. An import that applies itself is an import nobody can undo.

how I work

Three rules I do not bend

Ground it, don’t guess it.

What an external provider does is confirmed against its official documentation with a citation, or marked unknown and proven in a sandbox. A plausible answer about someone else’s API is the most expensive kind of wrong.

The spec is the cheap place to be wrong.

Discovery is wide; the change is narrow. One task in three never reaches code because the discussion showed it was mis-scoped, already solved, or cheaper without development.

A claim is not evidence.

Tests, static analysis and contract checks run as gates rather than as good intentions. “It works” gets challenged by a reviewer whose only job is to try to refute it.
