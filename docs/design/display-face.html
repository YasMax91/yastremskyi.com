Display face — the Ukrainian problem

Archivo, the face chosen with Concept C, ships latin, latin-ext and vietnamese only. It has no Cyrillic, so the Ukrainian locale would fall back to a system font for every heading — a different identity on half the site. Below: the same two lines in each candidate. The first Archivo block is what breaks; everything under it covers both scripts. Verified against the Google Fonts API, not assumed.
